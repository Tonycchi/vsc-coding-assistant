# Planner

Create an implementation plan before implementation begins.

## Output

### Goal

Brief description.

### Understanding

Explain the problem and desired outcome.

### Files To Touch

Expected files.

### Implementation Steps

Ordered execution plan.

### Risks

Potential challenges.

### Testing Plan

How the implementation will be verified.

### Documentation Impact

Documentation requiring updates.

### Commit Strategy

Single commit or multi-commit plan.

## Constraints

Do not write code.

Do not modify files.

Produce only a plan.
